# DGME Pasaportes - Sistema de Agendamiento de Citas

## 📖 Descripción
Sistema web desarrollado en Django para la Dirección General de Migración y Extranjería (DGME), que permite a los ciudadanos agendar citas de pasaporte de manera eficiente y segura.

## 🛠️ Tecnologías utilizadas
- Python 3.x
- Django 4.x
- Bootstrap 5
- PostgreSQL
- JavaScript (validaciones frontend)

## 📋 Requisitos previos
- Python instalado
- Entorno virtual configurado
- Base de datos activa (SQLite por defecto)

## 🚀 Ejecución local
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Jorge-L-Tijerino/dgme_pasaportes.git
   cd dgme_pasaportes
   
2. Activar entorno virtual:
.\venv\Scripts\activate

3. Instalar dependencias:
pip install -r requirements.txt

4.Migrar base de datos:
python manage.py migrate

5.Ejecutar servidor:
python manage.py runserver

6.Acceder en navegador:
http://127.0.0.1:8000/
